# Leaarning_python

Personal learning repository for Python. This repo contains my practice code, exercises, lab solutions, notes, and short explanations created while following online courses and tutorials (freeCodeCamp, Cisco materials, and ChatGPT-assisted study). The materials here are my own work and reflect my learning progress and struggles.

## Purpose
- Keep track of practice exercises, small projects, and study notes.
- Record how I solved problems and what I learned.
- Provide examples and references for personal revision and to help others learn from my experience.

## What you will find
- Python exercises and small projects (my solutions).
- Markdown notes, lesson summaries, and short how‑tos.
- Links to external course pages and references (I do NOT include proprietary course PDFs or official answer keys).
